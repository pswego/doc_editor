# 문서공방 — HWP · PDF 편집기

브라우저에서 한글(HWP/HWPX) 문서와 PDF를 열고 고치는 편집기입니다. 서버 없이 동작하며, 연 문서는 이 기기 브라우저(IndexedDB)에만 저장됩니다.
화면 구성은 디자인 레퍼런스(홈 · HWP 편집 · PDF 편집 · 디자인 토큰)를 따릅니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 에 정적 파일 생성 (아무 정적 호스팅에 올리면 됨)
npm test           # 형식 변환 테스트
HWP_SAMPLES=폴더 npm test   # 폴더 안의 .hwp 파일을 모두 읽고 HWPX 왕복까지 확인
```

## 배포 (GitHub Pages)

`index.html`은 Vite 개발용 원본이라 저장소를 그대로 Pages에 올리면 빈 화면이 나옵니다. 빌드 결과를 올려야 합니다.

1. 푸시하면 `.github/workflows/pages.yml`이 테스트 → 빌드 후 `dist/`를 `gh-pages` 브랜치에 올립니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**, Branch를 **gh-pages / (root)**로 지정합니다.

## 기능

### 한글 문서 (HWP · HWPX)
- **열기**: HWP 5.0 바이너리(OLE 복합 문서)와 HWPX(OWPML)를 직접 해석합니다. 글자 모양(글꼴·크기·굵게·기울임·밑줄·취소선·위/아래 첨자·글자 색·형광펜·자간), 문단 모양(정렬·줄 간격·왼쪽/오른쪽 여백·들여쓰기/내어쓰기·문단 위/아래 간격), 개요 1~3, 표(셀 병합·열 너비·셀 배경), 그림, 쪽 나누기, 편집 용지(크기·방향·여백)를 가져옵니다.
- **편집**: 리본 메뉴(파일 · 편집 · 입력 · 서식 · 쪽 · 검토 · 보기 + 표/그림 상황 탭), 왼쪽 개요/쪽 탐색, 오른쪽 서식 패널(글자 모양 · 문단 모양 · 쪽 설정), 찾기·바꾸기, 모양 복사, 문자표, 날짜 넣기, 기능 검색(Ctrl+K), 선택 영역 미니 툴바.
- **쪽 윤곽 보기**: 실제 용지 크기와 여백으로 쪽을 나누어 보여 줍니다. 문단은 줄 단위로 다음 쪽에 넘어가고, 쪽 번호가 표시됩니다. 웹 보기로 바꿀 수 있습니다.
- **저장**: HWPX로 저장(내려받기). HWP 5.0 바이너리로 쓰기는 지원하지 않으므로 `.hwp`로 연 문서도 HWPX로 저장합니다(한글 2010 이후에서 열림). 텍스트(.txt) 내보내기.
- **PDF로 내보내기 / 인쇄**: 편집 용지 크기·여백을 그대로 쓴 인쇄 화면을 엽니다. 인쇄 창에서 ‘PDF로 저장’을 고르면 PDF가 만들어집니다.
- **서식 문서**: 보고서(개조식), 공문서(기안문), 이력서, 회의록, 계약서.

### PDF
- **보기**: pdf.js로 렌더링, 썸네일·책갈피, 문서 내 찾기, 배율·폭 맞춤·회전.
- **주석**: 형광펜·밑줄·취소선(글자 드래그), 메모, 텍스트 상자, 펜, 사각형, 타원, 화살표, 도장(검토 완료·승인·반려 등). 색·불투명도·굵기 선택, 끌어서 옮기기·크기 바꾸기, 주석 목록에서 의견과 답글.
- **텍스트 편집**: 원래 글자를 눌러 그 자리에서 고치기(원문 자리를 흰색으로 덮고 다시 씀), 새 글자 넣기.
- **페이지**: 끌어서 순서 바꾸기, 회전, 복제, 지우기, 빈 페이지 넣기, 다른 PDF 끼워 넣기, 선택한 페이지 추출.
- **양식**: AcroForm 칸(텍스트·체크박스·목록) 채우기.
- **서명**: 손글씨/이름으로 서명을 만들어 이 브라우저에 보관하고 원하는 위치에 넣기, 날짜 넣기.
- **변환**: PDF → PNG(ZIP), 텍스트, 한글 문서(편집 가능한 HWPX 문서로 열기).
- **저장**: 모든 변경을 pdf-lib로 PDF에 반영해 내려받습니다. 메모와 의견은 PDF 메모 주석으로도 남겨 다른 뷰어에서 보입니다. 페이지 구성을 바꾸지 않은 문서는 원본을 그대로 고쳐 써서 양식·책갈피가 유지됩니다.

### 홈
최근 문서·즐겨찾기·휴지통, 문서 검색, 끌어 놓아 열기, PDF 합치기·나누기, 파일 변환.

## 구조

```
src/
  home/            홈 화면, 합치기·나누기, 변환 대화상자
  hwp/
    format/        hwp5.ts(HWP 5.0 읽기) · hwpx-read.ts · hwpx-write.ts · build.ts(공통 변환)
    editor/        TipTap 확장: 문단/글자 모양, 쪽 나누기, 쪽 윤곽(pagination), 찾기
    HwpEditor.tsx  편집 화면 · Ribbon.tsx · panels.tsx · CommandPalette.tsx
  pdf/
    PdfEditor.tsx  편집 화면 · PageView.tsx(페이지·주석 층) · PagesGrid.tsx · SignatureDialog.tsx
    save.ts        편집 상태 → PDF (pdf-lib, 한글 글꼴 포함)
    geometry.ts    PDF 좌표 ↔ 화면 좌표(회전 반영)
  lib/             저장소(IndexedDB), 파일, 변환 도구
public/fonts/      PDF에 넣는 한글 글꼴 (Noto Sans KR, 한글·라틴 하위 집합, SIL OFL)
```

## 알려진 한계
- HWP 3.0 이하, 암호가 걸린 문서, 배포용 문서는 열 수 없습니다.
- 머리말/꼬리말, 각주, 글상자·도형의 위치, 다단, 수식(스크립트 외)은 가져오지 않습니다. 글상자 안의 글은 본문 문단으로 옮겨집니다. WMF/EMF 그림은 빠집니다.
- 개요 번호(자동 번호)는 글자로 저장되어 있지 않아 표시되지 않습니다.
- 생성한 HWPX는 python-hwpx 스키마 검증과 다시 열기 검사를 통과하지만, 이 저장소에서 한컴 한글로 직접 열어 본 것은 아닙니다.
- PDF 텍스트 편집은 한 줄(텍스트 조각) 단위이며 원래 글꼴 대신 본고딕으로 다시 씁니다. 한글 글꼴은 통째로 넣기 때문에 글자를 넣은 PDF는 약 3MB 커집니다(pdf-lib의 CJK 하위 집합 버그 회피).
- 서명은 그림으로 들어가며 공인 전자서명(인증서)은 아닙니다. PDF 암호 설정은 지원하지 않습니다.
- 쪽 수는 화면에서 계산한 값이라 한글 프로그램과 다를 수 있습니다. 표는 쪽 경계에서 나뉘지 않고 통째로 다음 쪽으로 넘어갑니다.
